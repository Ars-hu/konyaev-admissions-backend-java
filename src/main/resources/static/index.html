🛡️ Центр тестирования отказоустойчивости (Zero 500 Check)
Нажмите на любой тест или запустите автоматический прогон всех сценариев. Бэкенд перехватывает все исключения через GlobalExceptionHandler и гарантированно возвращает корректный HTTP 400 Bad Request вместо 500 ошибки.
🔢 Переполнение Long (Число > 2^63)
DELETE /api/admin/applications/999999999999999999999999999999999999999999
Передача числа, превышающего разрядность Long. Ожидается: HTTP 400 без 500 ошибки.
🔤 Буквы вместо числового ID
PATCH /api/admin/applications/abc_not_a_number/status
MethodArgumentTypeMismatch: текст вместо числа в URL path variable. Ожидается: HTTP 400.
📅 Некорректный формат даты
GET /api/slots-status/2026-99-99_invalid_date
DateTimeParseException: несуществующая дата. Ожидается: HTTP 400 «Некорректный формат даты».
💥 Битый JSON в теле запроса
POST /api/register (broken JSON payload)
HttpMessageNotReadable: некорректный JSON (пропущены кавычки/скобки). Ожидается: HTTP 400.
📝 Превышение длины (1000 симв.)
POST /api/register (fio: 1000 characters)
Validation error: длина поля превышает лимит @Size(max=255). Ожидается: HTTP 400.
⚠️ Нарушение правила 24 часов
POST /api/register (date: today, time: 09:00)
Бизнес-правило буфера времени приёма. Ожидается: HTTP 400 с понятным текстом отказа.
👥 Дубликат заявки на дату
POST /api/register (повторный телефон)
Защита от дублей. Ожидается: HTTP 400 «Вы уже записаны на эту дату».
🔒 Неавторизованный админ-запрос
GET /api/admin/applications (No Token)
Попытка получить данные без Bearer JWT. Ожидается: HTTP 401 Unauthorized (без 500).
